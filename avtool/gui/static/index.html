Quick start

        
Three moves, and your videos become transcripts and subtitles. Everything stays on this Mac.

        
    
          
  1. Add your videos. Drag files or whole folders from Finder onto the window, or click ＋ FILES / ＋ FOLDER.
    2. 
          
  2. Press START. Watch each file go EXTRACT › TRANSCRIBE › WRITE. You can keep using your Mac while it works.
    3. 
          
  3. Use the results. Click ▤ on a finished row to read the transcript, or import the .srt into Premiere or CapCut.
    4. 
        

        
Transcripts are saved next to each video unless you pick a custom folder in SETTINGS. A file that's already done is skipped next time, so finished work is never repeated.

Start, Stop & meters

        

          
▶ START
Transcribes every READY, STOPPED and retry-able FAILED file, one at a time. Your Mac is kept awake (if that switch is on).

          
■ STOP
Stops cleanly within a second or two: the file in progress is set back to STOPPED, temporary audio is deleted, and no half-written transcript is left behind. Press START to continue where it left off.

          
NOW
The file being worked on and its position in the batch (e.g. FILE 2/5).

          
Meter
48 segments for the whole batch. The violet tip is the live edge.

          
EXTRACT › TRANSCRIBE › WRITE
The three stages of the current file. Extracting pulls the sound out of the video, transcribing turns speech into text (the long part), writing saves the files.

          
PROGRESS · TIME LEFT
Overall percentage and an estimate that appears after the first file finishes (it learns your Mac's real speed).

          
Counters
 done ·  skipped ·  failed.

        

      


      

        
Settings

        
Settings are remembered between launches, and locked while a batch runs.

        

          
QUALITY knob
BEST (large-v3-turbo): the most accurate; use it for final work. BALANCED (medium): a bit faster. DRAFT (small): fastest, rougher. Click the knob to step, drag it up/down, click a label, or use the arrow keys. A model you haven't used before downloads once.

          
LANGUAGE
EN for English (recommended for your recordings). AUTO guesses from the first 30 seconds, which can be fooled by music or a non-English intro. ES for Spanish.

          
CAPTIONS
STANDARD: up to 42 characters × 2 lines, max 7 seconds each, for Premiere, CapCut, DaVinci and YouTube. REELS: short one-line captions (≈18 characters) for vertical video.

          
Boost quiet voices
Evens out loud and quiet speakers. Turn it on if audience questions (far from the mic) come out missing, then redo those files.

          
Include subfolders
When adding a folder, also add the videos inside its subfolders.

          
Redo finished files
Normally finished files are skipped. Turn this on to transcribe them again (e.g. after editing the glossary or changing quality). Remember to turn it off afterwards.

          
Keep Mac awake
Stops the Mac sleeping during long batches. Keep the charger in; closing the lid on battery still sleeps.

          
SAVE TRANSCRIPTS
NEXT TO VIDEO or a CUSTOM FOLDER (click CHOOSE…). Use a custom folder if your drive is read-only on the Mac.

          
OUTPUT FILES
Tap a chip to switch a format on or off. JSON is always made: it marks the file as finished.

        

      


      

        
Glossary

        
Names and terms Whisper should spell correctly: people (Evan, Dylan…), brands (Smooth Scaling, Lightning OS…). One per line, then SAVE GLOSSARY.

        
    
          
  • Fix a repeat mistake: write wrong spelling -> Right Spelling, e.g. Lightening OS -> Lightning OS. Fixes and capital letters are applied to every output file.
    • 
          
  • Keep it short (a few dozen terms). A very long list can make Whisper invent or repeat lines; the counter turns amber past 40.
    • 
          
  • Lines starting with # are notes and are ignored.
    • 
          
  • To apply a new glossary to finished videos, turn on Redo finished files and press START.
    •

Log

        
A running commentary: what was found, each file's result and speed, and the summary. Green = done, amber = skipped/stopped, red = failed. The same information is saved as log.txt next to your transcripts, and the app's own diagnostics go to ~/Library/Logs/AVTool.log.

Tips for best results

        
    
          
  • Use BEST quality for anything you'll publish; DRAFT is for quick checks.
    • 
          
  • Set the language to EN rather than AUTO for English talks.
    • 
          
  • Add names to the glossary before a big batch: Evan, guests, brands.
    • 
          
  • Charger in, lid open for long batches.
    • 
          
  • Test one short clip first when trying a new camera or mic setup.
    • 
          
  • Audience questions missing? Turn on Boost quiet voices and redo that file.
    • 
          
  • Big files on a spinning external drive take a few extra seconds each to read during EXTRACT. That's normal.
    • 
        

      


      

        
FAQ

        
Does anything get uploaded?
No. The app only talks to a tiny engine running on this Mac (127.0.0.1). The internet is used only to download a speech model the first time you use it.

        
How long does it take?
It depends on the Mac and the quality setting. The first file shows the real speed in the LOG (e.g. "12× real time" means a 48-minute video takes about 4 minutes). Apple-silicon Macs are typically several times faster than real time on BEST.

        
Why does a file say "already done"?
It has a finished .json next to it from an earlier run, so it's skipped. To transcribe it again, turn on Redo finished files.

        
Can I use my Mac while it works?
Yes. It may feel a little busier during TRANSCRIBE; everything else is fine.

        
What if I close the window in the middle?
It stops cleanly, like pressing STOP. Open the app, add the same files, press START, and finished ones are skipped.

        
Where do the transcripts go?
Next to each video, unless SAVE TRANSCRIPTS is set to a custom folder. Click ⌕ on a row to jump there.

        
Names are spelled wrong. What can I do?
Add them to the GLOSSARY (or a wrong -> Right fix), save, turn on Redo finished files, and run again.

        
Can it label who's speaking?
Not yet. New paragraphs start after pauses of 2+ seconds, which usually marks a question or answer. Speaker labels are on the roadmap.

        
My camera recorded two audio tracks. Which is used?
The first one that can be decoded. To choose another, use the Terminal version with --audio-track 2, or set it per file in config.toml.

        
What do DRAFT / BALANCED / BEST download?
Each quality level uses its own model (about 0.5–1.6 GB), downloaded once the first time you press START with it.

        
Which file types work?
Video: .mov .mp4 .mkv .webm .wmv. Audio: .mp3 .wav .flac .aac .m4a. Upper-case names like .MOV are fine. Hidden files and macOS "._" files are ignored.

        
How do I update AVTool?
In Terminal: cd ~/Documents/AVTool && bash update.command. Your glossary, settings and transcripts are kept.

      


      

        
Troubleshooting

        

          
Every file FAILED with "No such file or directory: 'ffmpeg'"
Fixed in V1.2. Run the update (see FAQ), then press START again.

          
ENGINE light is red
Something isn't installed. In Terminal: cd ~/Documents/AVTool && bash setup_mac.command.

          
"Can't write to …"
The drive is read-only on this Mac (often NTFS-formatted). Choose SAVE TRANSCRIPTS › CUSTOM FOLDER.

          
macOS asks about "files on a removable volume"
Click Allow so AVTool can read your external drive. To change it later: System Settings › Privacy & Security › Files and Folders.

          
A file shows NO AUDIO
That video has no sound track (screen recordings sometimes don't). Nothing to transcribe.

          
Model download is stuck
Check the internet connection, then press START again; it continues the download.

          
Text repeats, or lines appear over silence
The app filters most of these automatically. Note the file and time and let your developer know.

          
Still stuck?
Open the LOG tab, copy the red lines, and send them along with a screenshot.
